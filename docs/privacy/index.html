Scope & operator

This notice covers the public Ryckman Estates information website, operated by PrinceRedBeard. Contact: ryckmanestates@gmail.com.

It does not describe data handling inside the Ryckman Estates app and must not be used as an app privacy policy.

What the website does

The website has no login or account-registration form and does not display private app account data.

The website code uses no cookies, analytics, local storage, tracking scripts, embedded forms or external fonts. Its pages work without JavaScript.

Hosting

The website is hosted on GitHub Pages. GitHub processes technical request information, including IP addresses, under its own Privacy Statement.

Contact links

An email link opens your chosen email application. No message is sent unless you choose to send it. If you email support, the contact details and message you send are provided to the support inbox.

Include only what is needed to explain your question. For questions about support correspondence or a privacy request, contact ryckmanestates@gmail.com. This notice does not promise a retention period or deletion timeline for app information or support messages.
